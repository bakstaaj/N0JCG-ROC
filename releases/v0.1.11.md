# N0JCG Radio Operations Center v0.1.11

APRS map reliability and receive-operations release.

## Highlights

- Makes locally decoded APRS callsigns available to the optional aprs.fi map
  through checked-in systemd journal access.
- Extends the bounded APRS map journal scan for larger 24-hour histories.
- Adds receive-only APRS gain-test tooling and direct-RF versus digipeated
  frame evidence handling.
- Updates the operator guide with APRS map diagnostics and recovery steps.

## Validation

- Python compilation passed.
- The v0.1.11 DOCX was rendered to an 11-page PDF and all pages were visually
  reviewed for layout, clipping, and readability.
- Release archives contain no private configuration, runtime state,
  credentials, or temporary QA files.
