# N0JCG Radio Operations Center v0.1.10

ROC/WES packet-session reliability and weather-dashboard release.

## Highlights

- Moves persistent weather history charts to the Weather panel so the Overview remains aligned and readable.
- Raises the default LinBPQ Packet RMS window to `MAXFRAME=4` for faster, standards-compatible mailbox transfers.
- Includes the operator service-repair controls and receive-only RMS audio calibration surface.
- Keeps APRS, Winlink, weather, telemetry, and operator diagnostics in the current branded release package.
